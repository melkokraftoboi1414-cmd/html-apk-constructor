ANDROID CLOUD BUILD · TEST

HTML App Constructor

HTML faylingizni tanlang, kodlangan matnni nusxalang va GitHub Actions orqali Android debug APK yig'ing.

1. HTML faylni tanlang

Hozircha faqat bitta .html yoki .htm fayl. ZIP loyihalar keyingi bosqichda qo'shiladi.

Fayl tanlang va “Faylni tayyorlash” tugmasini bosing.

2. GitHub'da APK yig'ing

1) GitHub Actions sahifasini oching.
2) “Android APK” workflow'ni tanlang va “Run workflow” ni bosing.
3) “html_base64” maydoniga yuqoridagi nusxalangan kodni joylang.
4) Yashil “Run workflow” tugmasini bosing. Jarayon tugagach, run ichidagi Artifacts bo'limidan APK'ni yuklab oling.

Eslatma: GitHub workflow_dispatch input hajmi cheklangan. Ushbu sinov uchun HTML fayl 40 KB dan kichik bo'lishi kerak. ZIP hozircha qo'llanmaydi. APK debug imzoli bo'ladi; Play Market uchun release signing keyin qo'shiladi.
